# shape.australasiaeclipse.com

Founding community ballot for Australasia Eclipse 2028: event shape, funding model, governance and timing, and site-vetting weights.

- Static page served by GitHub Pages at shape.australasiaeclipse.com (see `CNAME`).
- Ballots are stored in the australasiaeclipse.com Supabase project through two database functions; the page never reads individual ballots.
- The community password is shared on the community calls; it is checked server-side.
- Add `?preview=1` to the URL to view the page with sample results.
